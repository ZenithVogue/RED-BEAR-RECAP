📖 အသုံးပြုနည်း လမ်းညွှန်

Red Bear Studio Edition ဖြင့် ဗီဒီယို Dubbing လုပ်ရန် အောက်ပါ အဆင့်များအတိုင်း လိုက်နာ ဆောင်ရွက်ပါ။

  1. ဗီဒီယို တင်ခြင်း (Upload) Step 1 ရှိ Dropzone ထဲသို့ MP4 / MOV / WEBM / MKV ဖိုင်ကို ဆွဲထည့်ပါ သို့မဟုတ် နှိပ်၍ ရွေးချယ်ပါ။ အများဆုံး ၁၀ မိနစ် ကြာချိန်အထိ ရှိသော ဗီဒီယိုများကို လက်ခံပါသည်။
  2. စာတန်း/စာသား ထုတ်ယူခြင်း (Extract Subtitles) “ရှေ့သို့ ဆက်သွားမည် (Next)” ကို နှိပ်လျှင် Step 2 ရှိ Raw Text ဘောက်ထဲသို့ ရောက်ရှိပါမည် — မူရင်း စာတန်းများ (တရုတ်/အင်္ဂလိပ်) ကို ထိုဘောက်တစ်ခုတည်းတွင် တိုက်ရိုက် Paste လုပ်၍ စစ်ဆေးတည်းဖြတ်နိုင်ပါသည်။
  3. မြန်မာဘာသာ ပြန်ခြင်း (Translate to Burmese) “📋 Copy Full Prompt” ကို နှိပ်ပါက Step 2 ရှိ Raw စာသား (ဥပမာ တရုတ်စာတန်းများ) ကို Movie Recap Dubbing System Prompt အပြည့်အစုံထဲ ထည့်သွင်း၍ Clipboard သို့ ကူးယူပေးပါမည် — ထို့ကြောင့် Gemini App ထဲတွင် Paste လုပ်ရုံဖြင့် အသုံးပြုနိုင်ပါသည်။ Gemini မှ ပြန်လာသော JSON အဖြေကို Step 3 တွင် Paste လုပ်သည်နှင့် Auto JSON Cleaner က သန့်စင်၍ မြန်မာလိုင်းများအဖြစ် ပြသပေးပါမည်။
  4. အသံ ရွေးချယ်ခြင်း (Choose Voice) Step 3 ရှိ Voice Persona ကတ် ၁၀ ခု အနက် နှစ်သက်ရာ အသံကို ရွေးချယ်ပါ။ “▶ အသံနမူနာ နားထောင်ရန် (Preview)” ခလုတ်ဖြင့် အသံကို ကြိုတင် နားထောင်ကြည့်နိုင်ပါသည်။
  5. အသံ အနိမ့်အမြင့် ချိန်ညှိခြင်း (Adjust Pitch) Pitch Slider ကို ဆွဲ၍ အသံ အနိမ့်အမြင့်ကို -30Hz မှ +30Hz အထိ ချိန်ညှိနိုင်ပါသည် (0Hz သည် မူလအသံ အတိုင်း ဖြစ်သည်)။
  6. အသံ ဖန်တီးခြင်း (Generate Voice Over) “🔊 အသံဖန်တီးပေးမည် (Generate Voice Over)” ကို နှိပ်ပါက Step 4 ရလဒ်စာမျက်နှာသို့ ရောက်ရှိပြီး ဗီဒီယိုကို ဖန်တီးပေးပါမည်။
  7. နောက်ဆုံး ရလဒ် ရယူခြင်း (Finalize) Step 4 တွင် ဖန်တီးပြီးစီးသော ဗီဒီယိုနှင့် အသံကို ကြည့်ရှုနိုင်ပြီး “🔄 ပြန်လည် ဖန်တီးမည် (Re-render)” ဖြင့် ပြန်လည် ဖန်တီးနိုင်သည်၊ “📥 စာတန်းထိုး ဒေါင်းလုဒ်ဆွဲရန် (.srt)” ဖြင့် စာတန်းထိုးဖိုင်ကို ဒေါင်းလုဒ် ဆွဲနိုင်ပါသည်။
  8. API Key များ ပြင်ဆင်ခြင်း (API Keys Setup) စာသား ထုတ်ယူရန် (AssemblyAI) နှင့် ဘာသာပြန်ရန် (Gemini) API Key များကို အောက်ပါ လင့်များမှ အခမဲ့ ရယူနိုင်ပါသည် —
    👉 Gemini API Key ရယူရန် ဤနေရာကို နှိပ်ပါ
    👉 AssemblyAI API Key ရယူရန် ဤနေရာကို နှိပ်ပါ
